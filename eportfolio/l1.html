Definition

CSS stands for Cascading Style Sheets. It describes how HTML elements are presented on screen, paper, or other media. CSS separates content from presentation: HTML holds the structure and content, while CSS defines the visual style. With CSS, you can control layout, typography, color, spacing, and responsive behavior across devices. CSS enables consistent styling across many pages through a single stylesheet and offers mechanisms for progressive enhancement of presentation.

Why use CSS?

CSS is used to define the styles for web pages including the design, layout and variations for different devices and screen sizes. CSS provides consistency across pages, reduces duplication, improves maintainability, and enables responsive and accessible design. Key reasons to use CSS include:

  • Separation of concerns — keeps content (HTML) distinct from presentation (CSS).
  • Reusability — one stylesheet can control many pages or components.
  • Efficiency — faster maintenance and updates; change a rule once to affect the whole site.
  • Accessibility & responsiveness — allows control for zoom, contrast, and device-specific rules.
  • Visual capabilities — layouts, transitions, animations, grid and flexbox, and custom properties.

Layers of a Webpage

Web pages are typically organized into three logical layers. Each layer has a distinct role and responsibility:

  1. Content layer (HTML) — provides structured content such as headings, paragraphs, lists, images and links. Use semantic HTML and accessible alt text for images. Keep content clear and concise.
  2. Presentation layer (CSS) — controls appearance: colors, typography, layout, spacing, and visual hierarchy. Ensure good contrast and readable typography, apply responsive rules, and avoid styling that breaks accessibility.
  3. Behavior layer (JavaScript) — adds interactivity, dynamic content changes, and enhanced user experience. Behavior should be progressive: the page should remain functional without JS for critical content.

Benefits & Capabilities

CSS provides a broad set of capabilities and important practical benefits:

  • Easy maintenance: change one stylesheet to update site-wide appearance.
  • Performance: smaller HTML files; cached stylesheets improve page load times.
  • Precise layout control: CSS Grid and Flexbox allow modern, robust layouts.
  • Reusable design tokens: custom properties (CSS variables) let you centralize theme values like colors and spacing.
  • Visual polishing: transitions, transforms, and filters add subtle, performant visual enhancements.
  • Print & accessibility: control print stylesheets and high-contrast or reduced-motion preferences.

Examples & Syntax Notes

CSS rules are made of a selector and a declaration block. Each declaration includes a property and a value:

selector { property: value; property2: value2; }

Simple example:

p { font-family: Arial, sans-serif; color: green; font-size: 16px; }

Three ways to include CSS:

  • External stylesheet — separate .css file linked via <link rel="stylesheet" href="style.css">. Best for multiple pages and consistent site-wide design.
  • Embedded/Internal stylesheet — placed inside the page within a <style> tag in <head>. Useful for page-specific styles that override external rules.
  • Inline styles — style attribute directly on an element (e.g., <p style="color:red">). Use sparingly for single adjustments; inline has highest specificity and overrides external and embedded styles.

Display property and element types

Elements are either block-level or inline by default. The display property controls rendering behavior:

 div, p { display: block; }
span, a { display: inline; }
.hidden { display: none; }

Classes and reuse

CSS classes are declared with a dot prefix and applied via the class attribute. Classes are the primary way to create reusable styles:

.highlight { background-color: yellow; color: black; padding: 6px; border-radius: 6px; }

Multiple classes can be combined on the same element:

<div class="highlight large">Important</div>

Grouping selectors

Grouping selectors reduces repetition and keeps CSS concise:

h1, h2, h3 { color: white; }

Prerequisite

Basic knowledge of HTML is required before learning CSS. Understanding semantic HTML elements (headings, paragraphs, lists, images, links, forms) makes it easier to apply meaningful, accessible styles.

Best Practices

  • Keep CSS modular and organized (use meaningful class names and separate concerns).
  • Prefer external stylesheets for maintainability and caching benefits.
  • Use variables for theme values and consistent spacing.
  • Test responsiveness across devices and respect user preferences (prefers-reduced-motion, forced-colors).
  • Provide sufficient contrast and readable font sizes for accessibility.

Quick Tips

  • Use semantic HTML for accessibility.
  • Start with a mobile-first approach: style for small screens then add breakpoints.
  • Keep CSS selectors specific but not overly specific; prefer classes over IDs for styling.
  • Use rem/em units for scalable typography and spacing.
