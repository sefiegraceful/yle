<main>
<h2>What are CSS Selectors?</h2>
<p>Selectors are patterns used in CSS to target specific HTML elements so you can apply styles to them. They act as the bridge between HTML content and the visual rules defined in CSS. Each selector type serves a purpose, from styling all elements at once to targeting a single item precisely.</p>

<div class="card">
<h3>1. Element Selector</h3>
<p>The <strong>element selector</strong> applies a style to all occurrences of a specific HTML tag. It’s the simplest and most common selector type.</p>
<pre>
p {
  color: red;
  font-size: 16px;
}
</pre>
<p>This affects every <span style="color:#ff8888">paragraph (&lt;p&gt;)</span> in the document. It’s best used for general, consistent styling across an entire site.</p>
</div>

<div class="card">
<h3>2. Class Selector</h3>
<p>The <strong>class selector</strong> starts with a period (<code>.</code>) and is used to style multiple elements sharing the same class name. It’s one of the most flexible selectors in CSS.</p>
<pre>
.notice { color: yellow; background-color: black; }
</pre>
<pre>
&lt;p class="notice"&gt;Take note of this important update.&lt;/p&gt;
</pre>
<p>Classes are reusable, meaning the same class can be assigned to many elements across different sections.</p>
</div>

<div class="card">
<h3>3. ID Selector</h3>
<p>The <strong>ID selector</strong> targets a single, unique element on the page. It uses a hash symbol (<code>#</code>) before the identifier name.</p>
<pre>
#main-title { font-size: 24px; color: crimson; text-align: center; }
</pre>
<pre>
&lt;h1 id="main-title"&gt;Welcome to my website&lt;/h1&gt;
</pre>
<p>Because IDs must be unique within a page, this selector is perfect for elements that only appear once, such as headers or footers.</p>
</div>

<div class="card">
<h3>4. Universal Selector</h3>
<p>The <strong>universal selector</strong> uses an asterisk (<code>*</code>) to apply styles to all elements in a webpage. It’s useful for setting consistent base styles like font or margin resets.</p>
<pre>
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
</pre>
<p>This ensures a uniform starting layout by resetting default browser spacing.</p>
</div>

<div class="card">
<h3>5. Group Selector</h3>
<p>The <strong>group selector</strong> combines multiple selectors separated by commas, allowing them to share the same style rules. This saves time and keeps your code clean.</p>
<pre>
h1, h2, h3 {
  color: white;
  text-transform: uppercase;
}
</pre>
<p>All headings (h1–h3) now have the same color and text formatting. It’s efficient for applying identical rules to similar elements.</p>
</div>

<div class="card">
<h3>6. Attribute Selector</h3>
<p>The <strong>attribute selector</strong> styles elements based on the presence or value of a specific attribute. It’s powerful for forms, links, or custom data attributes.</p>
<pre>
input[type="text"] {
  border: 2px solid red;
  padding: 8px;
}
a[target="_blank"] {
  color: orange;
}
</pre>
<p>These rules style only text input boxes and links that open in new tabs. Attribute selectors are especially handy in modern responsive designs.</p>
</div>

<h2>Quick Comparison</h2>
<ul>
<li><strong>Element</strong> — applies to all specific tags.</li>
<li><strong>Class</strong> — reusable for many elements.</li>
<li><strong>ID</strong> — targets a single unique element.</li>
<li><strong>Universal</strong> — affects everything on the page.</li>
<li><strong>Group</strong> — applies shared styles to several selectors.</li>
<li><strong>Attribute</strong> — targets elements based on attributes.</li>
</ul>

<h2>Tips and Good Practices</h2>
<ul>
<li>Use <strong>classes</strong> for reusable styles instead of IDs whenever possible.</li>
<li>Keep selector names meaningful and descriptive.</li>
<li>Avoid overusing universal selectors, as they can affect performance.</li>
<li>Combine selectors logically to keep your stylesheet organized and efficient.</li>
<li>Validate your CSS using browser developer tools to check if rules are applied correctly.</li>
</ul>

<h2>Example: Putting It All Together</h2>
<pre>
&lt;!DOCTYPE html&gt;
&lt;html&gt;
&lt;head&gt;
&lt;style&gt;
  * { font-family: Arial; }
  h1 { color: crimson; }
  .highlight { background-color: yellow; }
  #unique { border-bottom: 3px solid red; }
  a[target="_blank"] { color: orange; }
&lt;/style&gt;
&lt;/head&gt;
&lt;body&gt;
&lt;h1 id="unique"&gt;Lesson 5: CSS Selectors&lt;/h1&gt;
&lt;p class="highlight"&gt;This paragraph uses a class selector.&lt;/p&gt;
&lt;a href="https://example.com" target="_blank"&gt;External Link&lt;/a&gt;
&lt;/body&gt;
&lt;/html&gt;
</pre>

<h2>Summary</h2>
<p>Selectors are the foundation of CSS. They determine which HTML elements get styled and how. By mastering the six main types—element, class, ID, universal, group, and attribute—you can create precise, organized, and visually consistent webpages. These tools give developers full control over design while keeping HTML clean and semantic.</p>
