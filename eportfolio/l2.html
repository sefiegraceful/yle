What will we use in CSS / Structure of CSS

Basic tokens and parts used in CSS include curly braces { }, colons :, semicolons ;, selectors and declarations.

A complete CSS rule consists of:

  • Selector — the HTML element or pattern you want to style; it is used to find the elements on a webpage to which the CSS rules will apply.
  • Declaration block — a block of one or more declarations enclosed in braces { ... }.
  • Declaration — a single instruction that defines a specific style (a property and a value).
  • Property — the style attribute to modify (for example font-family, color).
  • Value — the specific setting assigned to a property (for example Arial, red).

How Do Style Sheets Work?

Style sheets are text files (or text embedded in an HTML document's head) that separate content from appearance. HTML contains the content and structure; CSS contains presentation rules. A stylesheet suggests to the browser how to render elements in a particular way.

When authoring CSS keep these traditional notes in mind (historical guidance from modules):

  1. Older practice: <style type="text/css"> (modern browsers accept <style> without the type).
  2. Historically some guides suggested enclosing CSS in HTML comments so older browsers would ignore it; today all modern browsers support CSS so this is no longer necessary.

Three Kinds of CSS

CSS can be added to pages in three ways. Each has use-cases, precedence, and trade-offs.

External Style Sheets

External styles are stored in separate .css files. They are ideal for site-wide consistency because a single file can style many pages. Benefits include easy updating and caching by browsers. External files contain only CSS rules and no HTML.

Embedded / Internal Style Sheets

Embedded styles appear inside a page inside a <style> block in the <head>. Use this for page-specific styles or temporary overrides. Embedded rules override external rules when both apply.

Inline Styles

Inline styles are written directly on an element with the style attribute. They affect only that element and have the highest specificity (override embedded and external rules). Use sparingly for one-off changes.

Syntax & Examples

Typical syntax examples:

/* external link example */
<link rel="stylesheet" href="style.css" type="text/css">

/* embedded */
<style type="text/css">
  p { font-family: Comic Sans MS; color: green; }
</style>

/* inline */
<p style="font-family:Arial; color:red">This is a styled paragraph.</p>

Notes and small rules:

  • When listing multiple font families, separate with commas: font-family: Arial, Helvetica, Verdana;
  • Separate declarations with semicolons: font-family:Arial; color:red; text-align:justify;

Creating and Linking External CSS

Steps to create a basic external CSS file:

  1. Open a blank document (Notepad or any editor).
  2. Type the CSS rules you want.
  3. Save the file with a .css extension (e.g., style.css).
  4. Link it inside your HTML head with: <link rel="stylesheet" href="sample.css" type="text/css">

CSS Comments

CSS supports comments to explain code or leave notes. Comments are ignored by browsers and useful for readability. Syntax:

/* This is a single-line or multi-line CSS comment */

Practical Tips & Best Practices

  • Prefer external stylesheets for multi-page sites to simplify maintenance.
  • Use embedded styles only when a page needs unique styling that overrides site-wide rules.
  • Avoid heavy use of inline styles; they make maintenance harder.
  • Organize rules logically (typography, layout, components) and comment sections for clarity.
  • Test across browsers; modern browsers generally conform to current CSS specs.

Sample Code Demonstration

<!DOCTYPE html>
<html>
<head>
<title>Paragraphs</title>
<style type="text/css">
p{ font-family: Comic Sans MS; color: green; }
</style>
</head>
<body>
<p>This is the first paragraph.</p>
<p style="font-family:Arial; color:red">This is the third paragraph.</p>
</body>
</html>

Quick Notes

  • External > Embedded > Inline (in terms of maintainability and reuse).
  • Remember to keep CSS syntax accurate: selector { property: value; }
  • Use browser dev tools to inspect computed styles and cascade.
