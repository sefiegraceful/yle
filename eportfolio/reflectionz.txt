<p>This lesson taught me how CSS rules are made using selectors, properties, and values. I also learned there are three kinds of CSS — external, internal, and inline. I think external is the best because it can fix many pages fast. It made me want to write cleaner and neater code.</p>

<h2>Lesson 3 — Selectors & Properties</h2>
<p>I found out that selectors tell what part of a webpage to style. There are class and ID selectors too, which make styling easier. I liked learning how small CSS rules like colors and spacing can make a big change. It made me careful when I design my page.</p>
</div>
<div class="card">
<h2>Lesson 4 — Colors, Fonts, & Text</h2>
<p>I learned how to use different colors like RGB and HEX, and how to change fonts to make words look fun or serious. I also liked adding text shadows and spacing to make it look better. It showed me how choosing the right color and font makes a page more exciting to read.</p>
</div>
<div class="card">
<h2>Lesson 5 — My Reflection</h2>
<p>In Lesson 5, I learned how to use layout and simple CSS tricks to make my website look organized. It was fun to mix everything I learned before. I think CSS is really cool because it makes a boring website turn into something creative and beautiful.</p>
</div>
<div class="card">
<h2>Lesson 6 — Dimensions & Pseudo-Classes</h2>
<p>This lesson was fun because I learned how to control the size of things on a webpage using width and height.
