<section id="dimensions" class="card"><h2>CSS Dimensions</h2><p>The <strong>dimensions</strong> in CSS control the space an element occupies on a webpage. They help define how wide, tall, or visible elements are to ensure the layout looks balanced across devices.</p><h3>Width and Height</h3><p><strong>Width</strong> defines how wide an element is, while <strong>height</strong> sets its vertical size. Both accept values in <em>pixels (px)</em>, <em>percentages (%)</em>, <em>em</em>, or <em>auto</em>.</p><pre>div{width:200px;height:150px;}</pre><p>If you set <code>width:100%;</code>, the element expands to fill the available horizontal space.</p><h3>Min and Max Values</h3><ul><li><strong>min-width</strong>/<strong>min-height</strong> — the smallest size the element can shrink to.</li><li><strong>max-width</strong>/<strong>max-height</strong> — the largest size the element can expand to.</li></ul><pre>img{min-width:100px;max-width:300px;}</pre></section>
<section id="visibility" class="card"><h2>Visibility Property</h2><p>The <strong>visibility</strong> property decides whether an element is displayed or hidden. Unlike <code>display:none;</code>, hidden elements with <code>visibility:hidden;</code> still take up space in the layout.</p><h3>Possible Values</h3><ul><li><strong>visible</strong> — element is shown (default).</li><li><strong>hidden</strong> — element becomes invisible but keeps its space.</li><li><strong>collapse</strong> — used in table rows or columns to hide them entirely.</li></ul><pre>p{visibility:hidden;}</pre><p>This property is useful when temporarily hiding elements without affecting the overall page structure.</p></section>
<section id="pseudo" class="card"><h2>Pseudo-Classes in CSS</h2><p><strong>Pseudo-classes</strong> define styles based on the state of an element, like when a link is clicked, hovered, or visited. They make web pages more interactive and visually responsive.</p><h3>Common Link Pseudo-Classes</h3><ul><li><code>:link</code> — styles normal, unvisited links.</li><li><code>:visited</code> — styles links the user has already clicked.</li><li><code>:hover</code> — activates when the mouse pointer is over the link.</li><li><code>:active</code> — applies while the link is being clicked.</li><li><code>:focus</code> — applies when the element (e.g., a form input) is selected.</li></ul><h3>Order of Link States (LVHA)</h3><p>To ensure proper styling, pseudo-classes should appear in this specific order:</p><p><strong>LVHA — :link → :visited → :hover → :active</strong></p><p>This prevents conflicts between hover and active styles.</p><h3>Example:</h3><pre>a:link{color:lightblue;}a:visited{color:purple;}a:hover{color:red;text-decoration:underline;}a:active{color:yellow;}</pre></section>
<section id="examples" class="card"><h2>Code Example</h2><p>Here’s a short demo showing both dimension and pseudo-class properties together:</p><pre>&lt;!DOCTYPE html&gt;
&lt;html&gt;
&lt;head&gt;
&lt;style&gt;
.box{width:200px;height:100px;background-color:crimson;color:white;text-align:center;line-height:100px;}
a:link{color:cyan;}a:visited{color:purple;}a:hover{color:yellow;}a:active{color:orange;}
&lt;/style&gt;
&lt;/head&gt;
&lt;body&gt;
&lt;div class="box"&gt;Hover over &lt;a href="#"&gt;this link&lt;/a&gt;&lt;/div&gt;
&lt;/body&gt;
&lt;/html&gt;</pre></section>
<section id="summary" class="card"><h2>Summary</h2><ul><li>Dimensions define how large or small an element appears (using width, height, min/max).</li><li>Visibility controls whether an element is shown but still occupies space.</li><li>Pseudo-classes let you change appearance based on user actions (hover, click, visited).</li><li>LVHA order ensures consistent link styling.</li><li>Combining these allows better structure and interactivity in your web design.</li></ul></section>
