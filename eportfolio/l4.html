Lesson 4 — CSS Rules, Classes, and Grouping Selectors

Structure of CSS rules, six main property groups, classes, and grouping techniques

CSS Rules and Structure

A CSS rule defines how specific HTML elements should appear. Each rule has two parts: a selector that identifies which elements to style, and a declaration block containing one or more style declarations inside braces { }.

p {
  color: red;
  font-size: 18px;
}

The selector p targets all paragraph elements. Each declaration includes a property (like color) and a value (like red), separated by a colon and ending with a semicolon.

Six Main Groups of CSS Properties

GroupDescriptionExample
FontsDefine font family, size, weight, and style for text.
p { font-family: Arial; font-size:16px; }
Colors & BackgroundsControl element colors and background styles.
body { background-color:black; color:white; }
TextAdjust alignment, spacing, and decoration of text.
h1 { text-align:center; text-transform:uppercase; }
Boxes & LayoutHandle spacing, borders, padding, and element positioning.
div { margin:20px; padding:15px; border:2px solid red; }
ListsModify bullets, numbering, and indentation.
ul { list-style-type:square; }
Tag ClassificationDefine how an element behaves in layout flow.
img { display:block; }

Using Classes in CSS

Classes let designers reuse style rules on different elements. A class starts with a period (.) in CSS and is applied in HTML using the class attribute.

.golden { color: blue; }
.sodapop { color: red; }

This paragraph text is blue.


This div text is red.

You can combine multiple classes for layered effects:

.highlight { background-color: yellow; color: black; }
.big-text { font-size: 24px; font-weight: bold; }

This text is both highlighted and large.

Element + Class Selectors

The element + class selector (element.classname) is more specific than a simple class. It targets only the chosen element type using that class.

.note { background-color: yellow; }
p.note { color: blue; }

This paragraph has blue text on yellow background.


  • This list item only inherits the yellow background.

    Grouping Selectors

    Grouping selectors let you apply the same rules to multiple selectors at once, separated by commas. This reduces repetition and keeps code shorter.

    h1, p {
  color: white;
  background-color: black;
}

    The same color and background style now apply to both headings and paragraphs. Grouping improves consistency and reduces file size.

    Summary

    • Every CSS rule follows the pattern selector { property: value; }.
    • Six groups of properties organize all styling options.
    • Classes are reusable style labels applied with the class attribute.
    • Element + Class selectors refine styles to a specific tag.
    • Grouping selectors keep code concise and consistent.
